# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org),
version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the
work. Harassment, discrimination, and personal attacks are not tolerated.

Full text: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

Report unacceptable behavior to **sysknife-development@protonmail.com**. Reports are handled
confidentially.
